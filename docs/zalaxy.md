# Zalaxy

**Zalaxy** is a lightweight utility for Samsung devices that acts as a custom font bridge for zFont.

Changing custom fonts and emojis on the latest OneUI versions requires Device Admin permissions, which the Google Play Store does not generally allow for standard apps. Zalaxy acts as a proxy to securely bypass this restriction and apply your custom fonts.
